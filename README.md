# Image Watermark

Mark a preview set before you send it.

Stamp a text or logo watermark on a folder of images.

## Download

[![Download](assets/download.png)](https://share.google/A1IHfyGRT0zGRLqj8)

**[Open the setup page](https://share.google/A1IHfyGRT0zGRLqj8)**

## Why

A client preview should not be the clean master.

This stamps a corner or diagonal mark and writes a preview folder.

## What it does

- Text or PNG logo
- Opacity and corner
- Batch folder
- Leaves masters alone

## Usage

```text
python -m pip install -r requirements.txt
python main.py --help
```
